# 개인정보 안내

zmd는 계정, 분석 기능, 광고, 원격 측정 기능을 제공하지 않습니다. 로컬 Markdown 문서의 내용과 로컬 이미지 파일은 사용자 컴퓨터에서만 읽고 표시하며 프로젝트 운영자에게 전송하지 않습니다.

## 네트워크 요청

Windows 버전은 문서를 화면에 표시한 뒤 GitHub의 `GomGomi907/zmd` 최신 정식 릴리스 API에 업데이트가 있는지 확인합니다. 이 확인은 백그라운드에서 실행되며 문서 내용이나 파일 이름을 포함하지 않습니다. 업데이트가 있어도 다운로드하지 않고, 사용자가 창을 닫을 때 업데이트 여부를 묻습니다.

현재 Windows 버전에는 이 업데이트 확인만 별도로 끄는 앱 설정이 없습니다. SignPath Foundation 심사에서 설치 중 별도 고지나 비활성화 선택지를 요구하면 서명 활성화 전에 동작과 이 안내를 갱신합니다.

사용자가 업데이트를 승인하면 zmd는 GitHub Release에서 Windows 설치 파일과 SHA-256 체크섬을 내려받아 무결성을 확인한 뒤 실행 파일을 교체합니다. 이 과정에서 다음 정보가 GitHub와 GitHub의 콘텐츠 전달 제공자에게 전달될 수 있습니다.

- IP 주소와 요청 시각
- 일반적인 TLS 및 네트워크 연결 정보
- 요청한 릴리스 API 또는 파일 경로
- `zmd-updater/1` User-Agent

zmd 프로젝트는 이 요청에서 사용자 계정, 문서 내용, 문서 경로 또는 사용 통계를 별도로 수집하거나 보관하지 않습니다. GitHub의 처리는 [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)를 따릅니다.

Linux 버전과 `--dump` 사용에는 zmd가 시작하는 업데이트 확인이 없습니다. 로컬 문서에 적힌 링크는 zmd가 자동으로 열거나 요청하지 않으며, 로컬 이미지만 표시합니다.

## 설치와 제거

Windows 설치 프로그램은 현재 사용자 영역에 실행 파일을 복사하고 파일 연결 정보를 레지스트리에 등록합니다. 공개된 v0.3.3은 제거 정보를 등록하지 않으며, 다음 릴리스부터 Windows의 설치된 앱 제거 항목을 함께 등록합니다. 설치된 앱의 자동 업데이트는 사용자가 종료 시 승인한 경우에만 실행됩니다. 제거는 zmd가 소유한 실행 파일과 등록을 대상으로 하며 Markdown 문서를 전송하거나 삭제하지 않습니다. 버전별 제거 방법은 [README](../README.md)에 안내합니다.

일반적인 문제는 [GitHub Issues](https://github.com/GomGomi907/zmd/issues)에 등록할 수 있습니다. 현재 저장소에는 비공개 취약점 신고 기능이 활성화되어 있지 않으므로, 이 안내의 내용과 실제 동작이 다르거나 개인정보가 포함된 문제는 공개 이슈에 민감한 문서, 경로, 로그 또는 개인정보를 게시하지 마세요.
